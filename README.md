# Быстрый переезд на новый Mac

Личная настройка Mac: программы Homebrew, профиль iTerm2 и опциональная базовая настройка zsh. Список программ и оформление сверены с ноутбуком 6 октября 2026. Основная цель — Apple Silicon.

## Новый Mac: порядок действий

1. Завершите начальную настройку macOS. На рабочем Mac дождитесь корпоративного управления и установки обязательных приложений.
2. Откройте Terminal. Если Git ещё недоступен, установите Command Line Tools:

   ```bash
   xcode-select --install
   ```

   Дождитесь завершения установки, затем скачайте репозиторий:

   ```bash
   git clone https://github.com/kostinos/ITERM2_my_setings.git
   cd ITERM2_my_setings
   bash setup.sh --dry-run --shell
   ```

3. Просмотрите `Brewfile`: удалите ненужные программы перед установкой. Затем запустите:

   ```bash
   bash setup.sh --shell
   ```

   Скрипт при необходимости запускает официальный установщик Homebrew, устанавливает пакеты, добавляет профиль iTerm2 и настраивает shell. Установщики могут запросить пароль администратора или действия в интерфейсе macOS. Запускайте от обычного пользователя, без `sudo` перед скриптом.

4. Откройте iTerm2 → Settings → Profiles, выберите **Kostinos** и назначьте его основным через Other Actions → Set as Default. Начните новую сессию терминала.
5. Проверьте результат:

   ```bash
   bash setup.sh --check --shell
   ```

   Код выхода 0 означает, что перечисленные пакеты, управляемый профиль и shell-фрагмент присутствуют и соответствуют репозиторию. Это не проверка логинов, разрешений macOS или работоспособности каждой программы.

## Что делает скрипт

- `bash setup.sh` устанавливает программы и отдельный динамический профиль iTerm2.
- `--shell` дополнительно устанавливает Oh My Zsh при его отсутствии и подключает `shell.zsh` в конец `.zshrc` (учитывает `ZDOTDIR`). Для новой конфигурации используются тема `robbyrussell` и плагин `git`, как на исходном ноутбуке, плюс completions и syntax highlighting.
- `--dry-run` показывает план без скачивания и записи файлов.
- `--check` проверяет состояние без установки.
- `requirements.sh` оставлен как совместимый вход: принимает те же флаги.

Повторный запуск не добавляет повторную строку в `.zshrc`. Перед заменой управляемых файлов и первым изменением `.zshrc` создаются копии `.backup.*` (профиль — в отдельной папке `ProfileBackups`, shell-файлы — рядом с оригиналом). Существующий профиль Default сохраняется. Установка использует `--no-upgrade`: Homebrew не выполняет плановое обновление уже установленных пакетов, но может обновить необходимые зависимости.

Shell-фрагмент сохраняет существующую конфигурацию Oh My Zsh, если `.zshrc` уже задаёт `ZSH`. Если shell настроен сложнее, сначала прочитайте `shell.zsh` или запускайте без `--shell`.

На Intel предусмотрен путь Homebrew `/usr/local`, но полный переезд на Intel не проверен; состав пакетов ориентирован на Apple Silicon.

## Состав репозитория

| Файл | Назначение |
|---|---|
| `Brewfile` | Верхнеуровневые formulae и casks из текущего Homebrew |
| `setup.sh` | Установка, предварительный просмотр и проверка |
| `shell.zsh` | Базовая публичная конфигурация shell |
| `iTerm2-Dynamic.json` | Автоматическая установка отдельного профиля Kostinos |
| `Default.json` | Ручной импорт через Profiles → Other Actions → Import JSON Profiles |

Профиль содержит цвета, Monaco 12 / Menlo 12, размер 90 × 54 и неограниченный scrollback. Динамический профиль копируется в `~/Library/Application Support/iTerm2/DynamicProfiles/kostinos.json`. Изменения этого профиля лучше сохранять в репозитории: повторная установка восстановит его содержимое из файла.

## Что перенести отдельно

- Программы вне Homebrew: например, Visual Studio Code, Telegram, Figma, ChatGPT, Keka, Bambu Studio, Ollama и Tailscale. Установите необходимые с официальных сайтов; наличие приложения на исходном Mac не означает, что оно нужно на новом.
- Корпоративные программы, лицензии и внутренние инструменты — через штатный процесс IT/MDM.
- SSH-ключи, VPN, сертификаты, доступы GitHub и менеджер паролей — через отдельный защищённый перенос. Авторизацию `gh auth login` выполните после установки.
- Git author: задайте `user.name` и `user.email` для личных и рабочих репозиториев отдельно.
- Данные приложений, Obsidian vault, проекты, настройки VS Code и браузеров — из резервной копии или штатной синхронизации.
- Разрешения macOS: Accessibility, Screen Recording, Full Disk Access и другие — по необходимости для конкретных приложений.

Этот репозиторий не заменяет резервную копию. Профили экспортированы без личных путей, команд, переменных окружения, клавиатурных макросов и triggers. Не добавляйте сюда секреты, историю shell или полный экспорт системных настроек.

## Обновление списка программ

Сначала посмотрите актуальный список на основном Mac:

```bash
brew leaves
brew list --cask
```

Перенесите нужные позиции в `Brewfile` строками `brew "имя"` и `cask "имя"`. Проверьте, что в публичный список не попали внутренние taps или приватные инструменты. Не используйте `brew bundle cleanup` при переезде: удаление лишних программ не входит в настройку.

## Откат настроек

- Для iTerm2 выберите прежний Default. Чтобы убрать динамический профиль, удалите только `kostinos.json` из папки DynamicProfiles.
- Для shell удалите строку `source "$HOME/.config/kostinos-mac/shell.zsh"` из `.zshrc` или восстановите нужную резервную копию. Затем откройте новую сессию.
- Программы Homebrew удаляются отдельно по необходимости; автоматического удаления нет.

Документация: [установка Homebrew](https://docs.brew.sh/Installation), [Homebrew Bundle](https://docs.brew.sh/Manpage#bundle-subcommand), [динамические профили iTerm2](https://iterm2.com/documentation-dynamic-profiles.html).
