# Настройки macOS и iTerm2

Обновлено 6 октября 2026 по установленным программам и профилю iTerm2 на Mac с Apple Silicon.

## Программы Homebrew

`Brewfile` содержит установленные верхнеуровневые formulae и casks из публичных источников. Зависимости Homebrew установит автоматически.

```bash
bash requirements.sh
```

Нужен установленный [Homebrew](https://brew.sh). Скрипт устанавливает недостающие пакеты без планового обновления уже установленных. На новом Mac сначала добавьте Homebrew в PATH по инструкции установщика.

Программы, установленные вне Homebrew, корпоративные приложения и внутренние taps сюда не включены. Этот список не является полной резервной копией ноутбука.

## Профиль iTerm2

В iTerm2 откройте Settings → Profiles → Other Actions → Import JSON Profiles и выберите `Default.json`. Если профиль Default уже существует, проверьте импортированный профиль перед назначением его основным.

Профиль содержит текущие цвета, параметры отображения, шрифты Monaco 12 / Menlo 12, размер 90 × 54 и неограниченный scrollback.

Экспорт намеренно содержит только параметры оформления и терминала. Команды, пути, переменные окружения, клавиатурные макросы, triggers и служебные идентификаторы не экспортируются. Настройки shell (`.zshrc`, плагины, алиасы) настраиваются отдельно.
